# Хроники Тьмы

[![CI](https://github.com/SergeiLPanov/textGame/actions/workflows/ci.yml/badge.svg)](https://github.com/SergeiLPanov/textGame/actions/workflows/ci.yml)

Консольная RPG на Go: исследуй локации, сражайся с монстрами, выполняй задания, прокачивай героя и побеждай боссов. Без внешних зависимостей, только стандартная библиотека.

## Возможности

- **6 локаций:** Тёмный лес, Гнилое болото, Старый замок, Старое кладбище, Пещера кобольдов, Деревня эльфов, плюс магазин. В части локаций есть вложенные места (например, оружейная и сокровищница замка, мавзолей и семейный склеп).
- **Пошаговые бои:** атака, защита, отступление, использование предметов и четыре заклинания (огненный шар, ледяная стрела, удар молнии, луч света). Заклинания расходуют ману.
- **Типы монстров:** звери, гуманоиды, нежить и боссы. У нежити есть сопротивления и уязвимости: например, огонь и лёд по ней слабы, а луч света наносит повышенный урон.
- **Боссы:** некромант и король кобольдов, с отдельным событием при падении здоровья ниже половины.
- **Прокачка:** опыт, уровни, рост здоровья, маны и урона. Враги масштабируются под уровень героя.
- **Инвентарь и экипировка:** оружие и броня, расходники (зелья здоровья и маны), пассивные предметы, трофеи и квестовые предметы.
- **Задания в деревне эльфов:** принеси ушей гоблинов, праха нежити или клыков волков и получи награду.
- **Магазин:** покупка зелий, мечей и брони за золото.
- **Сохранение и загрузка** прогресса в JSON-файл.
- **ASCII-арт:** экраны боя и локаций с полосками здоровья и маны.

## Запуск

Нужен Go 1.25 или новее.

```bash
git clone https://github.com/SergeiLPanov/textGame.git
cd textGame
go run .
```

Или собрать бинарник:

```bash
go build -o game .
./game
```

Управление: в каждом меню вводится номер пункта и нажимается Enter. Пункт `9` в главном меню сохраняет игру, при выходе игра предложит сохраниться. Сохранение лежит в файле `save.json` рядом с игрой; при следующем запуске можно продолжить или начать заново.

## Тесты

```bash
go test ./...
go test -race ./...
```

Тесты покрывают основные модули: игрока и прокачку, врагов и сопротивления, бой, инвентарь, экипировку, мир и сохранение/загрузку.

## Структура проекта

| Файл | Назначение |
|---|---|
| `main.go` | главное меню, игровой цикл, старт и выход |
| `player.go` | герой: характеристики, урон, опыт, уровни, заклинания, экипировка |
| `enemy.go` | монстры, классы, сопротивления, масштабирование под уровень |
| `fight.go` | бой, меню боя, боссы |
| `world.go` | локации и магазин |
| `elfvillage.go` | деревня эльфов и квесты |
| `inventory.go` | предметы и инвентарь |
| `equipment.go` | экран экипировки |
| `save.go` | сохранение и загрузка (JSON) |
| `render.go`, `assets/` | отрисовка боёв и локаций, ASCII-спрайты |
| `story.go` | тексты и описания |
| `constants.go` | игровой баланс: характеристики, цены, награды |
| `input.go` | ввод пользователя |
| `*_test.go` | тесты |

Баланс (здоровье и урон монстров, стоимость предметов, множители) вынесен в `constants.go`, поэтому его можно менять, не трогая логику.

## Что можно улучшить

- Разнести доменную логику и точку входа по пакетам (`internal/...`).
- Вынести тексты в отдельные файлы вместо Go-кода.
- Добавить новые локации, заклинания и классы героя.
